# 🎸 Rock de los 80 - Web Awwwards

Una web espectacular tipo Awwwards sobre el **Rock de los años 80**.

## Descripción

El rock de los años 80 fue una época muy importante para la música. Este estilo se desarrolló principalmente en Estados Unidos y Reino Unido, con una estética exagerada y teatral.

## Contenido

- **Características del contexto**: Sintetizadores, MTV, cultura juvenil, grandes conciertos
- **Subgéneros**: Hard rock, Glam rock, Pop rock, Heavy metal
- **Artistas**: Queen, Bon Jovi

## Tecnologías

- HTML5
- CSS3 (Animaciones avanzadas, Glassmorphism, Neon effects)
- JavaScript Vanilla (Intersection Observer, Custom Cursor, Parallax)
